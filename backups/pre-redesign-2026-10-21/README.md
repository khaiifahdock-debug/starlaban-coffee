# Starlaban pre-redesign backup

These are exact copies of the website and app immediately before the 2026-10-21 redesign.

- Restore the website by replacing the repository root `index.html` with this folder's `index.html`.
- Restore the app by replacing `app/index.html` with this folder's `app-index.html`.

The original pages load images and scripts from the existing `assets/` folder; keep those files in place.
